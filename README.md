# Playerok Auto-Bump Bot

Telegram-бот для автоматического поднятия лотов на маркетплейсе [Playerok](https://playerok.com).

## Возможности

- Добавление лотов в фильтры по URL (название, цена и стоимость поднятия определяются автоматически).
- Автоподнятие по расписанию с равномерным распределением по минутам цикла.
- Несколько циклов одновременно — каждый со своим набором фильтров и временем старта.
- Независимые фильтры с собственным интервалом.
- Лимит расходов на каждый фильтр.
- Пауза/возобновление отдельных лотов.
- Уведомления в Telegram о каждом поднятии (с кликабельной ссылкой на лот).
- Статистика поднятий и расходов за разные периоды.

## Стек

- Python 3.11+
- aiogram 3.x
- PlayerokAPI (неофициальный)
- APScheduler
- SQLite + SQLAlchemy

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# отредактируй .env, добавь TELEGRAM_TOKEN, ADMIN_ID и cookies Playerok
python main.py
```

## Настройка cookies Playerok

1. Открой playerok.com в браузере и залогинься.
2. F12 → Application → Cookies → playerok.com.
3. Скопируй значения cookies (как минимум `token` и `__ddg3`).
4. Передай их боту через `/login` или впиши в `.env`.
