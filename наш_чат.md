## Что мы сделали

### 1. Фикс бесконечного цикла калибровки
**Проблема:** Когда нет фильтров с `top_position`, бот уходил в бесконечный цикл калибровки.

**Фикс в `scheduler/bumper.py`:**
```python
else:
    if not self._board_trackers:
        # No top_position filters enabled — nothing to calibrate, just idle
        await asyncio.sleep(10.0)
        continue
    logger.info("SMART BUMP: no calibration data — doing calibration bump to bootstrap timing")
```

### 2. Мульти-пользовательская поддержка

**Архитектура:** Каждый пользователь получает полностью изолированный рантайм:
- Своя БД: `data/bot_{telegram_id}.db`
- Свои cookies Playerok
- Свой BumpEngine
- Свой AutoRestoreEngine

**Новые файлы:**

#### `database/registry.py`
```python
@dataclass
class UserRecord:
    telegram_id: int
    playerok_cookies: str
    playerok_user_agent: str

class UserRegistryStore:
    # Хранит список пользователей в data/users.json
    # Атомарное сохранение через .tmp + os.replace
```

#### `core/user_context.py`
```python
class UserContext:
    telegram_id: int
    db: Database
    playerok: PlayerokClient
    bump_engine: BumpEngine
    restore_engine: AutoRestoreEngine

class UserContextRegistry:
    async def create_and_start(self, rec: UserRecord) -> UserContext
    async def stop_and_remove(self, telegram_id: int) -> bool
    async def stop_all(self) -> None
    def get(self, telegram_id: int) -> UserContext | None
```

#### `bot/middleware.py`
```python
class UserContextMiddleware(BaseMiddleware):
    # Незарегистрированных пользователей тихо игнорирует
    # Инжектит db, playerok, bump_engine, contexts, store, admin_id
```

#### `bot/handlers/users.py`
Команды только для админа:
- `/adduser` — добавить пользователя (FSM: ID → cookies)
- `/removeuser ID` — удалить пользователя
- `/listusers` — список всех пользователей (🟢/🔴 статус)
- `/cancel` — отменить FSM

#### `main.py`
- Автомиграция `bot.db` → `data/bot_{admin_id}.db`
- Загрузка всех пользователей из `data/users.json` при старте
- `/start` виден всем, `/adduser` `/removeuser` `/listusers` — только в меню админа

### 4. Как добавить друга в бота

1. Написать боту `/adduser`
2. Ввести его Telegram ID
3. Ввести его cookies с Playerok (строка из браузера)
4. Сказать другу написать `/start` боту
